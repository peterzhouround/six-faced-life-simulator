# 六面世界：第二人生

一个纯前端、可存档、可重开的六面世界题材人生模拟文字冒险。无需数据库或付费服务器，可直接部署到 GitHub Pages。

## 已实现

- 自定义或随机开局：身份、种族、时代、出生地、人生愿望
- 体魄、魔力、剑术、学识、魅力、钱币、声望、人物羁绊
- 由年龄、地点、属性和已发生剧情共同筛选的事件
- 可点击的 15 地点完整地图：区域资料、危险度、旅行成本、已解锁/未解锁状态
- 自由行动输入：支持自行描述修炼、调查、工作、交谈、休息、探索和旅行
- 属性门槛选项、旅行、成长、冒险者委托、学院路线和阶段结算
- 以原创改写方式穿插转移事件、Dead End 归乡路线、菲托亚搜救、拉诺亚特别生与贝卡利特远征等原著节点
- 每步自动存档、三个手动存档位、读取/覆盖/删除
- 随时重开且保留手动存档
- 导出个人传记为 TXT
- 桌面、平板和手机响应式布局
- 原创生成的奇幻主视觉，不使用动画截图或官方美术素材
- 中文采用加粗宋体，英文和数字采用 Times New Roman

## v4：生计、路线与旅行（2026-08-31）

- 口粮、疲劳、士气和全套行装耐久加入存档。修炼花费1钱币、1口粮；疲劳85及以上需要先休息。旅行消耗由路程决定；装备耗损后可付费保养。
- 生计快捷行动：包饭工作、采集口粮、免费休息，均推进一个月。没有钱或食物仍可恢复，不会卡死；工作疲劳过高时收入较低。
- 商店出售口粮、药品、铁剑、法杖、皮甲和斗篷。装备实际影响对练/旅行，已买装备可免费切换，不会因为换装消失。
- 12个成长节点，每60人物经验获得1点：魔术路线、剑术基础及三流派专精、生存路线。高级招式检查领域经验与路线前置；旧存档已学会的招式保留。
- 15个地点各有两条随机旅途反馈；“转移前夕”独享准备事件。31个条件剧情、21项技能、8类日常；遭遇以规则结算，不是独立地图战斗。
- 五地区声望独立保存，影响物价；身份/种族改变部分初次交往数值和世界反馈。地区专属委托、人物关系网暂未实现。
- 自由输入细分火、水、土、风、治愈与三种剑术。休息、工作、采集优先按单一行动处理；无火系路线时只研究理论，不直接学会火球。
- 手机默认折叠详细属性，底部常驻角色、剧情、选项、技能、地图、存档入口。五项新手目标可点击前往对应功能。
- v1/v2/v3存档读取时迁移至v4，保留人物、剧情和已学技能，补入8份初始口粮和基础行装；v4读取不重复发放补给。

规则回归：`node tests/rules-v4.cjs`。测试包含旧档迁移、经济与恢复、技能前置、对练和300回合模拟。移动端以桌面浏览器的320×568、360×640、390×844视口验证，不等同于所有真实手机浏览器。

仍然是免费、离线规则驱动的同人游戏，不连接大模型。音效、雷达图、人物关系网及完整多结局属于后续阶段，本版未加入。

## v3：成长与羁绊更新（历史版本）

- 30个条件剧情事件、8类日常事件（另有开局和阶段结算），穿插洛琪希教学、艾莉丝成长、魔大陆归乡、保罗重逢、龙神交汇、学院与迷宫线索等原创改写。
- 20项魔术、剑术和生活技能；人物等级、F—S冒险者等级、七阶领域评定，三种剑术流派分别积累经验。阶位与经验是本作简化规则，不代表原著认证或唯一神级称号。
- 技能对练可攻击、治疗、格挡、打断与恢复，消耗魔力/体力；对练每回合自动存档，关闭弹窗可以暂停。
- 10位角色专属互动文案，20/40羁绊触发一次性信任与约定篇章。远方关系以书信与训练记录抽象呈现，不是角色实时行程模拟。
- 八个主要交汇节点之间至少需要5—8次支线活动，并保留年龄/地点条件；修炼与人物互动以月为单位，不再直接跳过当前剧情。
- v1/v2自动与手动存档读取时迁移到v3，不重置人物、历史和关系。保存格式仍使用原来的浏览器键名。
- 手机角色创建与长技能弹窗支持纵向滚动；确认按钮保留在可操作区域。

自由输入仍然是本地关键词规则，并未连接 DeepSeek 或其他大模型，不会生成无限剧情。原著节点为非官方同人改写，路线可以偏离原著；当前内容不包括后期小说结局。

## 本地运行

直接打开 `index.html` 即可游玩。为了获得和线上相同的行为，建议在本目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

## 存档说明

存档使用浏览器 `localStorage`，因此：

- 同一设备、同一浏览器、同一网址下可以继续游戏；
- 清理浏览器站点数据会删除存档；
- 换设备不会自动同步；
- 导出的 TXT 是人生记录，不是可导入的游戏存档。

## GitHub Pages

仓库设置为从 `main` 分支根目录发布即可。项目没有后端、构建流程或密钥，不会产生服务器费用。
