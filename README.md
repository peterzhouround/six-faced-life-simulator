# 六面世界：第二人生

一个纯前端、可存档、可重开的六面世界题材人生模拟文字冒险。无需数据库或付费服务器，可直接部署到 GitHub Pages。

## 已实现

- 自定义或随机开局：身份、种族、时代、出生地、人生愿望
- 体魄、魔力、剑术、学识、魅力、钱币、声望、人物羁绊
- 由年龄、地点、属性和已发生剧情共同筛选的事件
- 属性门槛选项、旅行、成长、冒险者委托、学院路线和阶段结算
- 每步自动存档、三个手动存档位、读取/覆盖/删除
- 随时重开且保留手动存档
- 导出个人传记为 TXT
- 桌面、平板和手机响应式布局
- 原创生成的奇幻主视觉，不使用动画截图或官方美术素材

## 本地运行

直接打开 `index.html` 即可游玩。为了获得和线上相同的行为，建议在本目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

## 存档说明

存档使用浏览器 `localStorage`，因此：

- 同一设备、同一浏览器、同一网址下可以继续游戏；
- 清理浏览器站点数据会删除存档；
- 换设备不会自动同步；
- 导出的 TXT 是人生记录，不是可导入的游戏存档。

## GitHub Pages

仓库设置为从 `main` 分支根目录发布即可。项目没有后端、构建流程或密钥，不会产生服务器费用。
